## 🌟 Overview
**SGPAToPercentage.in** is a fast, 100% private, client-side single-page web tool built using HTML5, Tailwind CSS, Lucide Icons, and Vanilla JavaScript. It enables Indian technical university students to accurately convert their semester SGPA, CGPA, or SPI marks into official percentage according to specific university ordinances.

---

## 🎓 Supported Indian Universities & Formulas

| University | State | Formula |
| :--- | :--- | :--- |
| **AKTU** (Dr. APJ Abdul Kalam Tech Univ) | Uttar Pradesh | `(SGPA - 0.75) × 10` |
| **GTU** (Gujarat Technological University) | Gujarat | `(SPI - 0.5) × 10` |
| **VTU** (Visvesvaraya Technological Univ) | Karnataka | `(CGPA - 0.75) × 10` |
| **SPPU** (Savitribai Phule Pune University) | Maharashtra | `(CGPA × 8.8) + 12` |
| **RGPV** (Rajiv Gandhi Proudyogiki Vishwavidyalaya) | Madhya Pradesh | `CGPA × 10` |
| **JNTUH / JNTUK** (Jawaharlal Nehru Tech Univ) | Telangana / AP | `(CGPA - 0.5) × 10` |
| **GGSIPU / IPU** (IP University) | Delhi NCR | `CGPA × 9.5` |
| **RTU Kota** (Rajasthan Technical Univ) | Rajasthan | `(CGPA - 0.75) × 10` |
| **BPUT** (Biju Patnaik Univ of Tech) | Odisha | `(CGPA - 0.5) × 10` |
| **CSVTU** (Chhattisgarh Swami Vivekanand) | Chhattisgarh | `(CGPA - 0.75) × 10` |

## ✨ Features
- 🚀 **Zero Server Latency:** Runs 100% in browser using Vanilla JavaScript.
- 🎨 **Modern Mobile-First Design:** Styled with Tailwind CSS & Lucide Icons.
- 📜 **Recent History:** Saves last 5 calculations in `localStorage`.
- 📋 **Export & Share:** Copy result text, share via Web Share API, and generate printable summary report card.
- 🔍 **SEO Optimized:** Comprehensive SEO content, structured JSON-LD schema, Open Graph metadata.
